# Directory Analysis Tree – Disk Usage Analyzer

## About the Project
A Python-based disk usage analyzer that uses a Directory Analysis Tree to represent file system structures, display directory hierarchies, and analyze storage usage.

This project is developed as a Data Structures and Algorithms (DSA) case study by a team of four, focusing on tree-based organization and directory traversal.

## Features
- Visualize directory and file hierarchies.
- Calculate directory and file storage usage.
- Display disk information and directory sizes.
- Traverse and analyze directory structures using a tree-based approach.

## Technologies Used
- Python
- Directory Analysis Tree
- File System Operations

## Data Structure
The project uses a tree-based structure to represent directories and files. Directories act as parent nodes, while files and subdirectories are represented as child nodes. This structure supports hierarchical traversal and storage analysis.
